# داشبورد کنترل پروژه، تولید و انبار رام نور

برای نصب روی سرور شخصی، راهنمای SELF-HOST-fa.md را بخوانید. Node.js 24 یا بالاتر کافی است؛ دستور اجرای سرور مستقل: `node server.mjs`.

تمام کدهای رابط کاربری در public/dashboard، منطق مشترک در operations.mjs، سرور شخصی در server.mjs و API نسخه میزبان در app/api/factory قرار دارد. source/raw-sheets.json داده استخراج‌شده فایل اصلی است. برای بازسازی داده پایه: `node tools/prepare-data.mjs`. این فرمان گزارش‌ها و موجودی ثبت‌شده در SQLite را تغییر نمی‌دهد.

پوشه‌های db و drizzle طرح و migration نسخه میزبان‌اند. برای نصب شخصی به npm install یا ساخت Vinext نیاز ندارید. فایل پایگاه داده و صف آفلاین جزو کد منبع نیستند؛ برای انتقال داده‌های ثبت‌شده از پشتیبان استفاده کنید.
